# Habitica CSVアップローダー

CSVからHabiticaのタスクを読み込み、プレビュー・入力検証・重複確認を経て一括登録するブラウザ用ツールです。ToDo・日課・習慣・ごほうびに対応します。

## セットアップと使い方

アプリ自体に追加ライブラリやビルドは不要です。以下のファイルを同じフォルダーに置いてください。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面 |
| `styles.css` | 見た目 |
| `csv.js` | CSV解析・タスク変換・入力検証 |
| `app.js` | 画面操作・Habitica API通信 |
| `sample.csv` | UTF-8 BOM付きサンプル4件 |

1. `index.html` をブラウザで開きます。ファイルを直接開けない環境では、プロジェクトフォルダーで `python -m http.server 8000 --bind 127.0.0.1` を実行し、ブラウザでローカルサーバーの `index.html` を開いてください。
2. 「サンプルCSVを保存」からCSVを保存し、UTF-8で編集します。
3. CSVを選択し、プレビューの内容とエラーを確認します。エラー行がある間は登録できません。
4. Habiticaの設定 → APIで確認したUser IDとAPI Tokenを入力し、「接続テスト」を行います。
5. 重複を除外するか確認して「確認して一括登録」を押します。開始前と送信前に確認ダイアログが出ます。
6. 処理後はHabitica側でも登録内容を確認してください。

ローカルサーバーは使い終わったら Ctrl+C で停止します。インターネットへの公開は不要です。

## CSVの列

ヘッダーの大文字小文字と前後の空白は無視します。値の前後の空白も除去します。カンマ・改行・引用符を含むフィールドは引用符で囲み、値の引用符は `""` とします。空行は読み飛ばし、エラーにはCSVの物理行番号を表示します。

| 列 | 内容 |
| --- | --- |
| `type`（必須） | `todo` / `daily` / `habit` / `reward`。従来の別名（習慣、日課、ToDo、タスク、ごほうび、toDo、todos、dailies、habits、rewards）にも対応 |
| `text`（必須） | 空でないタイトル |
| `notes` | 詳細 |
| `priority` | `0.1` / `1` / `1.5` / `2` |
| `date` | ToDoのみ。実在する `YYYY-MM-DD` 形式の日付 |
| `frequency` | 日課のみ。`daily` / `weekly` / `monthly` / `yearly` |
| `everyX` | 日課のみ。1以上の安全な整数 |
| `mon,tue,wed,thu,fri,sat,sun` | 日課のみ。曜日指定時は `frequency=weekly`（省略時はweeklyを設定）。空欄の曜日はfalse |
| `up,down` | 習慣のみ。プラス・マイナスの有効/無効 |
| `value` | ごほうびのみ。0以上の有限数値 |

真偽値には `true/false`、`1/0`、`yes/no`、`on/off` を使用できます。対象の種類以外の任意列と、未知の列は従来どおり送信対象外です。CSVのヘッダーと種類を確認してください。

## 安全性と通信

- 認証情報をソース・ログ・ブラウザの永続ストレージに保存しません。入力中は画面のメモリーに保持され、Habitica APIへの認証に使用します。使用後はタブを閉じてください。
- 通信先は `https://habitica.com/api/v3/` です。CSV読み込みだけでは通信しません。
- X-Clientには入力されたUser IDと `-CSVUploader` を使用します。自分専用のツールとして利用してください。
- 重複判定は「種類＋前後空白を除去し小文字化したタイトル」です。同名の別タスクもスキップされるため、必要に応じてチェックを外してください。
- 通信は30秒でタイムアウトし、自動再送しません。送信中の失敗や中止では登録済みの可能性があります。再送前にHabiticaを確認してください。
- 「中止」は次の送信を止める要求です。送信済みの処理を取り消したり、登録済みタスクを削除したりする機能ではありません。
- CSVの値はHTMLとして解釈せず文字として表示します。APIのエラー本文もそのまま表示しません。
- 実アカウントによるCORS、X-Client要件、一括登録形式の検証は未実施です。公開前に[公式API資料](https://habitica.com/apidoc/)と[API利用ガイド](https://github.com/HabitRPG/habitica/wiki/API-Usage-Guidelines)を確認し、実アカウントで別途検証してください。

## 検証

CSV変換テスト（Node.js標準機能のみ）：

```sh
node tests/csv.test.js
node --check app.js
node --check csv.js
```

ブラウザテスト（PythonのPlaywrightと `/usr/bin/chromium` がある検証環境）：

```sh
python tests/browser_test.py
```

ブラウザテストは一時的なローカルHTTPサーバーを使用し、終了時に停止します。Habiticaへの通信はすべてモックします。アプリ利用のためにPlaywrightを導入する必要はありません。
