# Habitica CSVアップローダー

CSVからHabiticaのタスクを読み込み、プレビュー・入力検証・重複確認を経て一括登録するブラウザ用ツールです。ToDo・日課・習慣・ごほうびに対応します。

## 利用する

[Habitica CSVアップローダーを開く](https://yahisanemu-collab.github.io/HabiticaUploader/)

CSVを選択すると登録対象が一覧で表示されます。各行の「編集」でタイトル・詳細・種類・期限・曜日などを変更し、「保存」で反映できます。入力に誤りがある場合は、表示された内容を修正してください。「キャンセル」で編集を取り消せます。

不要な行は「削除」で登録対象から外せます。編集・削除しても元のCSVファイルやHabitica上の既存タスクは変更されません。

## CSVの列

ヘッダーの大文字小文字と前後の空白は無視します。値の前後の空白も除去します。カンマ・改行・引用符を含むフィールドは引用符で囲み、値の引用符は `""` とします。空行は読み飛ばし、エラーにはCSVの物理行番号を表示します。

| 列 | 内容 |
| --- | --- |
| `type`（必須） | `todo` / `daily` / `habit` / `reward` |
| `text`（必須） | タイトル |
| `notes` | 詳細 |
| `priority` | `0.1` / `1` / `1.5` / `2` |
| `date` | ToDoのみ。`YYYY-MM-DD` 形式の日付 |
| `frequency` | 日課のみ。`daily` / `weekly` / `monthly` / `yearly` |
| `everyX` | 日課のみ |
| `mon,tue,wed,thu,fri,sat,sun` | 日課のみ。曜日指定時は `frequency=weekly`（省略時はweeklyを設定）。空欄の曜日はfalse |
| `up,down` | 習慣のみ。プラス・マイナスの有効/無効 |
| `value` | ごほうびのみ（0以上） |

真偽値には `true/false`、`1/0`、`yes/no`、`on/off` を使用できます。対象の種類以外の任意列と、未知の列は従来どおり送信対象外です。CSVのヘッダーと種類を確認してください。

## User ID・API Tokenの確認方法

1. 利用するご本人のアカウントでHabiticaにログインします。
2. 「設定」→「API」を開きます。[API設定を開く](https://habitica.com/user/settings/api)
3. 「User ID（ユーザーID）」をコピーして、ツールの「User ID」に貼り付けます。
4. 「API Token（APIトークン）」を確認・コピーして、ツールの「API Token」に貼り付けます。非表示の場合は表示ボタンを押してください。
5. ツールの「接続テスト」を押して、接続成功の表示を確認します。

ログイン用のメールアドレスやパスワードを入力する必要はありません。API Tokenは他人に渡したり公開したりしないでください。

## 安全性と通信

- 認証情報をソース・ログ・ブラウザの永続ストレージに保存しません。入力中は画面のメモリーに保持され、Habitica APIへの認証に使用します。使用後はタブを閉じてください。
- 通信先は `https://habitica.com/api/v3/` です。CSV読み込みだけでは通信しません。
- 重複判定は「種類＋前後空白を除去し小文字化したタイトル」です。同名の別タスクもスキップされるため、必要に応じてチェックを外してください。
- 通信は30秒でタイムアウトし、自動再送しません。送信中の失敗や中止では登録済みの可能性があります。再送前にHabiticaを確認してください。
- 「中止」は次の送信を止める要求です。送信済みの処理を取り消したり、登録済みタスクを削除したりする機能ではありません。
- CSVの値はHTMLとして解釈せず文字として表示します。APIのエラー本文もそのまま表示しません。
